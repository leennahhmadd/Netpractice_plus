# Netpractice_plus
My solutions and configurations for the Netpractice project. It's all about figuring out subnet masks, IP addressing, routing tables, and fixing basic networking issues.

## What's this about?
Netpractice is a practical module to get comfortable with IPv4 networking:
- **IPs & Subnets:** Working out host ranges, masks, and network IDs.
- **CIDR:** Dealing with shortcuts like `/24` or `/28`.
- **Routing:** Setting up default gateways and static routes so packets actually go where they're supposed to.
- **Switches & Routers:** Connecting subnets without creating routing loops.

## Structure
- Contains the files and configurations for the levels.

## How to test
1. Open the Netpractice simulator.
2. Load up a level file.
3. Check that everything validates correctly.
